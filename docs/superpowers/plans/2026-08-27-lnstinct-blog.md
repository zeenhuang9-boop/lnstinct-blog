# lnstinct-blog 本地版实施计划

## 全局约束

- 项目根目录固定为 `E:\我的个人博客`，不向 C 盘创建项目文件。
- 公开身份仅使用“小泽 / lnstinct.”；不得出现真实姓名、学校、联系方式或家庭信息。
- 视觉采用“纸上生长”：暖纸、墨黑、锈红，支持亮暗主题与手机优先布局。
- 首发文章和散文为空；项目仅从当前可核验的公开 GitHub 仓库导入。
- 不提供评论、公开注册、定时发布、多人协作或批量删除。
- 外部部署必须等本地验收通过后再执行。

## Task 1：工程基础与领域契约

- 安全审查并固定 Next.js、React、Tailwind、Vitest、Playwright、Supabase 与 Tiptap 依赖。
- 建立 Next.js App Router、TypeScript、ESLint、测试命令、环境变量样例和基础目录。
- 先写失败测试，再实现 slug、内容状态转换、富文本白名单、Zod 表单验证与站点配置。

## Task 2：公开站点与设计系统

- 先写页面与组件行为测试，再实现全局布局、导航、主题切换和“纸上生长”视觉变量。
- 实现首页、项目、文章、散文、关于、详情、404、搜索、RSS、sitemap 和 robots。
- 数据源缺失时展示真实空状态，不生成示例内容。

## Task 3：Supabase 数据与权限

- 添加 posts、projects、admin_users、Storage bucket 和 RLS 迁移。
- 实现浏览器/服务端 Supabase 客户端、匿名公开读取和管理员写入仓储接口。
- 关闭应用内注册；缺少云端配置时给出明确配置页，不伪造登录成功。

## Task 4：手机写作后台

- 先写后台表单、删除确认、保存状态和权限行为测试。
- 实现登录、仪表盘、内容列表、Tiptap 编辑器、自动保存、预览、发布、撤回、回收站及项目管理。
- 永久删除只能处理一个明确 ID，并需要二次确认。

## Task 5：项目导入、文档与验收

- 通过 GitHub 官方公开接口核验并导入适合展示的项目元数据。
- 编写 README、Supabase 配置、管理员创建、备份恢复、测试与故障排查说明。
- 运行 lint、类型检查、单测、E2E、构建、隐私扫描、可访问性与移动端视觉检查。
