- 放行 Tiptap 官方 Markdown 解析器生成的安全链接默认属性与代码块语言属性，同时继续拒绝未知属性、危险协议和异常语言值。

- 新依赖来自 npm 官方注册表与 Tiptap 官方仓库，版本和现有 Tiptap 统一为 3.30.5。

- 这类检查只能降低供应链风险，不能诚实承诺“100% 没有任何危险”。
- Playwright 使用隔离目录 `.e2e-data/`，未覆盖现有 `data/` 中的两篇本地内容，也未连接公网 Supabase。
